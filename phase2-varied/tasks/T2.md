### T2 [math]
Take the 1D SIA with flux q = −Γ H^(n+2) |S_x|^(n−1) S_x and H_t = −q_x + b, with S = H + B. Assume a uniform bed slope B_x = −α with α > 0 and a uniform base state H = H0.

1. Linearize for a small perturbation h(x,t). Show that it follows an advection-diffusion equation and give c and the effective diffusivity in terms of Γ, n, H0 and α.
2. Discretize with forward Euler in time and centered differences in space, with spacing Δx. Use von Neumann analysis to get the amplification factor and the exact stability conditions on Δt.
3. Many codes use Δt ≤ Δx²/(2 D_max), where D = Γ H^(n+2) |S_x|^(n−1). Is this sufficient? Justify your answer using your result.
4. Compute all values for n = 3, A = 7.57e-17 Pa⁻³ a⁻¹, ρ = 900 kg/m³, g = 9.81 m/s², H0 = 200 m, α = 0.1, Δx = 100 m. Say which condition controls Δt.
5. Say what changes on the 2D staggered grid, and what changes if the upwind or centered choice for H at faces changes.

Show the derivations, then give the numbers in a small table.
