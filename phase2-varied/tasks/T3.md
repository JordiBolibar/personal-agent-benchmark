### T3 [Julia/SciML coding]
Write Julia code for a differentiable implicit diffusion step in 1D. The state is `u` (length N). The face diffusivities are `κ` (length N−1, interior faces only, no-flux at the ends), and `r = Δt/Δx²` is a fixed scalar.

Define the operator L(κ) by (L u)_i = −κ_i (u_{i+1} − u_i) + κ_{i−1} (u_i − u_{i−1}), dropping the terms at the ends. The step is `step(u_old, κ, r) = (I + r L(κ)) \ u_old`.

Requirements:
- The solve must be O(N), using a suitable structured matrix type.
- Write a `ChainRulesCore.rrule` for `step`. The pullback must return tangents for `u_old` and `κ`, and `NoTangent()` for `r`. It must also be O(N) and must not differentiate through the factorization.
- Reuse the factorization in the pullback if you can, and say if it is valid to do so.
- Write a short test that compares the rule against central finite differences for a random scalar projection of the output. Also include a dot-product style consistency check.

You cannot run the code, so check dimensions and signs by hand.

Output format: first one fenced Julia block with all the code. Then the mathematical derivation of the pullback. Then a list of edge cases, such as κ with negative entries, type stability and Float32 input.
