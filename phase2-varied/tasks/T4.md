### T4 [Julia/SciML coding]
This code should fit a neural diffusivity with an adjoint gradient. It fails, and even after a quick fix it would be unreliable. `H0` and `Hobs` are given vectors of length `N`.

```julia
using Lux, ComponentArrays, OrdinaryDiffEq, SciMLSensitivity, Zygote, Random
rng = Random.default_rng()
nn = Chain(Dense(1, 16, tanh), Dense(16, 1, softplus))
θ0, st = Lux.setup(rng, nn)
θ0 = ComponentArray(θ0)
const N = 50
const dx = 100.0
cache = zeros(N + 1)

function rhs!(dH, H, θ, t)
    for i in 2:N
        Hmid = 0.5 * (H[i-1] + H[i])
        Dmid, _ = nn([Hmid / 100], θ, st)
        cache[i] = -Dmid[1] * (H[i] - H[i-1]) / dx
    end
    dH .= (cache[1:N] .- cache[2:N+1]) ./ dx
end

prob = ODEProblem(rhs!, H0, (0.0, 10.0), θ0)
function loss(θ)
    sol = solve(prob, Tsit5(); p=θ, saveat=1.0,
        sensealg=InterpolatingAdjoint(autojacvec=ZygoteVJP()))
    return sum(abs2, sol[end] - Hobs) / N
end
g = Zygote.gradient(loss, θ0)
```
