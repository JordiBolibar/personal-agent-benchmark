## A — SIA slab, deformation only

**Setup.** Parallel-sided slab, thickness H, surface slope α (small), x along flow, z up from the bed. SIA means: the only nonzero deviatoric stress component is the shear τ_xz (simple shear), and the surface is traction-free, so the shear stress grows linearly with depth:

```
τ_xz(z) = ρ g sinα (H − z),   τ_b = ρ g H sinα
```

(the full driving stress reaches the bed; no membrane/longitudinal stresses).

**Glen's law in simple shear.** ε̇_xz = (1/2) ∂u/∂z = A τ_e^(n−1) τ_xz, and in simple shear τ_e = |τ_xz|, so

```
∂u/∂z = 2A [ρ g sinα (H − z)]^n
```

**Velocity profile** (integrate from u(0) = 0, no sliding):

```
u(z) = (2A / (n+1)) (ρ g sinα)^n [ H^(n+1) − (H − z)^(n+1) ]
```

Velocity increases with height as a power law in (H − z); all the shear is concentrated near the bed.

**Surface velocity (deformation):**

```
u_s = (2A / (n+1)) (ρ g sinα)^n H^(n+1) = (2A / (n+1)) H τ_b^n
```

**Depth-averaged velocity** (average the profile over [0, H]):

```
ū = (1/H)∫ u dz = (2A / (n+2)) (ρ g sinα)^n H^(n+1)
```

**Flux** (per unit width):

```
q = H ū = (2A / (n+2)) (ρ g sinα)^n H^(n+2)
```

**Diffusivity.** In general SIA the flow direction is down the surface gradient and sinα → |∇s|, so q = −D ∇s with

```
D = (2A / (n+2)) (ρ g)^n H^(n+2) |∇s|^(n−1)        (no sliding)
```

and the ice evolution is ∂H/∂t = ∇·(D ∇s) + M. Note the two key exponents: D ∝ H^(n+2) (very sensitive to thickness) and D ∝ |∇s|^(n−1) (the flux itself is ∝ slope^n; one power is pulled into D because the PDE is written against ∇s).

**With Weertman sliding, u_b = C τ_b^m.** SIA still puts the whole driving stress on the bed, so τ_b = ρ g H |∇s| is unchanged. Sliding adds a plug velocity on top of the same profile:

```
u_s = C τ_b^m + (2A/(n+1)) H τ_b^n
ū  = C τ_b^m + (2A/(n+2)) (ρ g sinα)^n H^(n+1)
q  = H u_b + q_def
  = H C (ρ g H |∇s|)^m + (2A/(n+2)) (ρ g)^n H^(n+2) |∇s|^n
```

Written as q = −D ∇s:

```
D = (2A/(n+2)) (ρ g)^n H^(n+2) |∇s|^(n−1)  +  C (ρ g)^m H^(m+1) |∇s|^(m−1)
      (deformation)                                (sliding)
```

**Ratio.** No sliding: ū/u_s = (n+1)/(n+2), i.e. u_s/ū = (n+2)/(n+1). For n = 3: u_s = 1.25 ū (ū = 0.8 u_s). Sliding adds the same velocity to every depth, so the profile becomes more plug-like and the ratio drops from (n+2)/(n+1) toward 1 as the sliding fraction grows. If R = u_b/u_def,s, then u_s/ū = (1+R)/(R + (n+1)/(n+2)); R → ∞ gives 1.

## B — Deformation and sliding at the point

Assumptions: the SIA of Part A exactly holds, A is correct, observed surface speed u_s = u_b + u_def,s. Slope 0.05 → α = 2.87°, sinα = 0.0499 ≈ 0.05 (0.1% error, negligible).

**Basal shear stress:**

```
τ_b = ρ g H sinα = 900 × 9.81 × 300 × 0.05 = 1.324×10^5 Pa ≈ 132 kPa
```

**Deformation speed** (n = 3, so 2A/(n+1) = 1.2×10^−24 Pa⁻³ s⁻¹):

```
u_def,s = (2A/(n+1)) H τ_b^n = 1.2e−24 × 300 × (1.324e5)^3
(1.324e5)^3            = 2.323e15 Pa³
1.2e−24 × 300 × 2.323e15 = 8.36e−7 m/s
```

Convert: 8.36×10⁻7 m/s × 3.156×10⁷ s/a = **26.4 m/a**.

**Implied sliding:**

```
u_b = 40 − 26.4 = 13.6 m/a   (34% of the surface speed comes from the bed)
```

## C — Effect of input errors

The sliding estimate is a residual: u_b = u_obs − u_def, with u_def ∝ H^(n+1) sin^n α = H⁴ slope³. So the sensitivity exponents are n+1 = 4 for H and n = 3 for slope, and both act on the big term, not on the small one.

| Perturbation | u_def (m/a) | inferred u_b (m/a) |
|---|---|---|
| none | 26.4 | 13.6 |
| H +10% (×1.1⁴ = 1.46) | 38.6 | 1.4 |
| H −10% (×0.9⁴ = 0.66) | 17.3 | 22.7 |
| slope +20% (×1.2³ = 1.73) | 45.6 | −5.6 (unphysical) |
| slope −20% (×0.8³ = 0.51) | 13.5 | 26.5 |

- H +10%: u_def grows 46%, sliding drops from 13.6 to 1.4 m/a (−90%).
- Slope +20%: u_def grows 73%, sliding goes negative (−5.6 m/a). A negative residual means the inputs or A are inconsistent, not that the glacier slides backwards. Do not clip it silently: it is diagnostic.
- Relative sensitivity of sliding: δu_b/u_b ≈ −(n+1)(u_def/u_b)(δH/H) − n(u_def/u_b)(δslope/slope) with u_def/u_b = 1.94. So −7.8 per unit relative H error, −5.8 per unit relative slope error. A 10% H error alone is ~78% error on u_b; a 20% slope error alone is ~116%. As independent errors (RSS): ±140%, i.e. u_b = 13.6 ± ~19 m/a. If both errors go the wrong way together, the answer ranges from about −27 to +31 m/a, so even the sign is not certain. This is why sliding inversions from surface data alone are ill-conditioned.

## D — Identifiability, extra data, and where SIA fails

**Can A and sliding be separated?**

- At one point: never. u_s = u_def(A, H, slope) + u_b(C, H, slope) is one equation with two unknowns. Every (A, C) pair on a trade-off line fits equally: soften the ice and the inferred sliding shrinks by exactly the same amount. This is the classic equifinality.
- With a spatial snapshot (u_s, H, slope over a glacier) and constant A, C: only weakly possible. The two terms must respond differently to the data, i.e. m ≠ n, and the data must span a wide range of driving stress. With m = n = 3 the two terms scale identically with slope and differ only by one power of H, so the columns are nearly collinear. Combined with the error amplification from Part C, the least-squares problem is badly conditioned: small noise becomes large swings in the A/sliding partition.
- The separation becomes possible when you break the degeneracy from outside: fix A independently, or add data with a different physical content (profile shape, time scales).

**Extra data that helps:**

1. Borehole inclinometry / tiltmeters: gives u(z) directly, the deformation/sliding split with no model assumption. The profile shape (Part A ratio) is the observable that separates the two.
2. Englacial temperature (borehole thermistors): A = A(T) is known, so the deformation term can be computed and removed; the residual is then sliding.
3. Time series of surface velocity: sliding responds to meltwater at daily–seasonal scales, viscosity-limited deformation changes only over years (temperature, geometry). A winter baseline plus a summer excess separates the two responses. Repeated GPS/stake/apRES measurements also give the vertical strain contribution.
4. Direct basal observations: ploughmeter, borehole camera, till deformation, basal water pressure (sliding depends on effective pressure, so pressure data constrain C and distinguish hard bed from till).
5. Full surface strain-rate fields, so a higher-order (membrane-stress) model can be inverted instead of SIA.

**Where SIA fails in a valley glacier, and the inversion bias:**

1. **Margins / valley walls.** Lateral drag supports part of the driving stress (Nye shape factor f ≈ 0.6–0.9, so effective stressing is f·τ_b, i.e. f³ ≈ 0.2–0.7 in deformation). SIA assumes all of τ_b drives shear, so it overestimates deformation for a given A. If A is fitted, the inversion compensates with ice that is too stiff (A_low = f^n A_true: at the margins, apparent hardening) and then underestimates sliding everywhere; if A is fixed externally, residual sliding near the walls is biased low, often negative. Surface speed also varies strongly across the width, which SIA cannot represent at all.
2. **Bed undulations, riegels, overdeepenings, the head and the snout.** Where slope or thickness changes fast, longitudinal stresses redistribute over a few ice thicknesses; the SIA relation τ_b = ρ g H ∇s is strictly local and wrong there. The inversion reads this model error as basal motion: spurious sliding patches that follow the topography, phase-shifted from any real bed property. Near the divide SIA deformation ∝ slope³ is nearly zero, so almost all observed motion is forced into "sliding"; near the snut/terminus, extension and thinning look like extra sliding.
3. **Tributary junctions and curved, convergent reaches.** Transverse flow, horizontal shear and side input of flux are outside the SIA stress state (and outside a flowline model's mass balance). The continuity mismatch is blamed on sliding, so confluences get spurious sliding maxima that are really 3D flow.
4. **Steep, crevassed terrain (icefalls, calving fronts).** sinα ≈ tanα and the small-slope force balance break down beyond ~10–20°; the continuum assumption also fails in crevasses. Inferred stresses and sliding there are meaningless; such zones should be masked out of any inversion.

All of this assumes isothermal ice with a single A; real thermal and water-content variations change A by orders of magnitude, which is one more reason a fixed-A sliding residual is only as good as the A you assume.
