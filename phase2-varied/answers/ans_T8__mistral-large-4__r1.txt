Assume `B` is independent of `H`, `n = 3` physically, and `H` may be zero at the terminus. Let `N = length(H)`.

## 1. Derivation

Faces are `k = 1:N-1`. Define

\[
S_i=B_i+H_i,\quad
s_k=\frac{S_{k+1}-S_k}{\Delta x},\quad
h_k=\frac{H_k+H_{k+1}}{2}
\]

\[
D_k=\Gamma h_k^{n+2}|s_k|^{n-1},\quad q_k=-D_k s_k
\]

and the RHS is

\[
f_1=f_N=0,\qquad
f_i=\frac{q_{i-1}-q_i}{\Delta x}\quad (2\le i\le N-1).
\]

Then

\[
\lambda^\top f
=
\frac1{\Delta x}\sum_{i=2}^{N-1}\lambda_i(q_{i-1}-q_i)
=
\sum_{k=1}^{N-1}\bar q_k q_k ,
\]

with the face adjoint weights

\[
\bar q_1=\frac{\lambda_2}{\Delta x},\quad
\bar q_k=\frac{\lambda_{k+1}-\lambda_k}{\Delta x}\ (2\le k\le N-2),\quad
\bar q_{N-1}=-\frac{\lambda_{N-1}}{\Delta x}.
\]

Equivalently, pad the interior adjoint with zeros:

\[
\bar q=\frac{\operatorname{diff}((0,\lambda_2,\dots,\lambda_{N-1},0))}{\Delta x}.
\]

The endpoint values `λ_1` and `λ_N` must not enter, because `f_1=f_N=0`.

For each face,

\[
\frac{\partial q_k}{\partial s_k}
=
-D_k-s_k\frac{\partial D_k}{\partial s_k}
=
-D_k-(n-1)D_k
=
-nD_k ,
\]

and

\[
\frac{\partial q_k}{\partial h_k}
=
-s_k\frac{\partial D_k}{\partial h_k}
=
-(n+2)\Gamma h_k^{n+1}|s_k|^{n-1}s_k .
\]

Since

\[
\frac{\partial s_k}{\partial H_k}=-\frac1{\Delta x},\quad
\frac{\partial s_k}{\partial H_{k+1}}=+\frac1{\Delta x},\quad
\frac{\partial h_k}{\partial H_k}=
\frac{\partial h_k}{\partial H_{k+1}}=\frac12,
\]

define

\[
s=\bar q_k\frac{\partial q_k}{\partial s_k}\frac1{\Delta x},\qquad
h=\bar q_k\frac{\partial q_k}{\partial h_k}\frac12 .
\]

Then the correct accumulation is

\[
\mathrm{out}[k]\ {+}{=}\ h-s,\qquad
\mathrm{out}[k+1]\ {+}{=}\ h+s .
\]

Note: `out[1]` and `out[N]` are generally nonzero. “End cells are frozen” means `dH[1]=dH[end]=0`, not that the gradient w.r.t. `H[1]`, `H[end]` is zero.

## 2. Errors in the given `vjp_H!`

1. **Wrong boundary adjoint weights.**  
   `q̄ = diff(λ) ./ Δx` uses `λ_1` and `λ_N`, but `dH[1]=dH[end]=0`, so those components of `λ` cannot affect `λᵀ dH`. The correct weights zero-pad the interior adjoint. Effect: spurious `-λ_1/Δx` in `q̄_1` and `+λ_N/Δx` in `q̄_{N-1}`, corrupting the gradient near both boundaries. This is hidden in a toy test if `λ_1=λ_N=0`, but in a real backward solve the adjoint variables of frozen cells are not automatically zero, so the boundary gradients are wrong.

2. **Missing derivative of `D` through `|dS|`.**  
   `dqdS = -c.D` is wrong. Since `q=-D dS` and `D` also depends on `dS`, the correct value is `dqdS = -n c.D`. Effect: the slope-sensitivity part is too small by a factor `n`; for Glen `n=3` it is 3x too small in magnitude.

3. **Swapped sign of the `dS` chain rule.**  
   Because `dS_k=(S_{k+1}-S_k)/Δx`, increasing `H_k` decreases `dS_k`, and increasing `H_{k+1}` increases it. The code does `out[k] += h + s`, `out[k+1] += h - s`, which is the opposite. Correct is `out[k] += h - s`, `out[k+1] += h + s`. Effect: the entire `dS` contribution to the gradient has the wrong sign at every face.

4. **`D ./ Hf` NaNs when `Hf = 0`.**  
   On real glacier geometries you can have `H_k=H_{k+1}=0`, e.g. at/outside the terminus on a sloping bed, so `Hf=0` and `D=0`, giving `0/0 = NaN`. Effect: NaNs propagate into `out`. Use the explicit derivative `-(n+2) Γ Hf^(n+1) |dS|^(n-1) dS`, which is finite for `n=3`.

5. **Blind reliance on the shared forward cache `c`.**  
   `vjp_H!` reads `c.dS`, `c.Hf`, `c.D` but does not guarantee they were computed from the `H` passed to this call. In a real adjoint solve running backward, `c` may already have been overwritten by another `rhs!` evaluation, a solver stage, dense output, or a finite-difference check. Effect: the VJP is silently evaluated at the wrong state. Recompute from `H` and `p` inside `vjp_H!`, or use a checkpointed cache proven to match `(H, t)`.

6. **Minor API issue: no `return out`.**  
   The last expression is the `for` loop, so the function returns `nothing`. It still fills `out`, but any caller using the return value breaks. Add `return out`.

## 3. Corrected `vjp_H!`

```julia
function vjp_H!(out, λ, H, p, t)
    (; B, Γ, n, Δx) = p
    # If Γ or B depend on t in the real model, evaluate them at this t.

    # Recompute face quantities at this H. Do not trust a shared forward
    # cache unless it is checkpointed for this exact (H, t).
    S  = B .+ H
    dS = diff(S) ./ Δx
    Hf = (H[1:end-1] .+ H[2:end]) ./ 2
    D  = Γ .* Hf .^ (n + 2) .* abs.(dS) .^ (n - 1)

    # Only interior λ enter, because dH[1] = dH[end] = 0.
    λeff = zeros(eltype(λ), length(λ))
    λeff[2:end-1] .= λ[2:end-1]
    qbar = diff(λeff) ./ Δx

    dqdS  = -n .* D
    dqdHf = -(n + 2) .* Γ .* Hf .^ (n + 1) .* abs.(dS) .^ (n - 1) .* dS

    out .= 0.0
    @inbounds for k in eachindex(qbar)
        s = qbar[k] * dqdS[k] / Δx
        h = qbar[k] * dqdHf[k] / 2
        out[k]     += h - s
        out[k+1]   += h + s
    end
    return out
end
```

## 4. Test plan

Use a pure reference RHS so Enzyme/finite differences are not confused by the mutable cache:

- `rhs_pure(H, p)` computes the same `dH` without writing into a shared `c`.
- Fix `n = 3.0`, `Γ = 1.3`, `Δx = 1.0` for a unit-scaled test. Use `N = 16`.
- Use several `H` states:
  - generic positive smooth glacier: `H = 0.2 .+ (1 .- x) .+ 0.1 .* rand(N)`;
  - zero-thickness tail on a sloping bed: last two `H` values exactly `0` while `B` still changes, to hit `Hf = 0`;
  - flat surface `S = B + H = const`, so `dS = 0` but `Hf > 0`;
  - a few random positive states with different seeds.
- For every case use random `λ = randn(N)` and deliberately set `λ[1]` and `λ[end]` nonzero. Also test `λ = e_1` and `λ = e_N`: the exact gradient must be all zeros, because `dH[1]=dH[end]=0`. The original code fails these two immediately.

Validation:

1. Enzyme: compute the VJP of `H -> rhs_pure(H, p)` with cotangent `λ`, using Enzyme’s VJP/pullback API. Compare with `vjp_H!`. With O(1) scaled inputs expect near machine precision: `isapprox(out, ref; rtol = 1e-9, atol = 1e-11)`.
2. Finite differences: for each cell `j`, central-difference the scalar `φ(H) = dot(λ, rhs_pure(H, p))` with step `ε = 1e-6`:  
   `ref[j] = (φ(H + ε e_j) - φ(H - ε e_j)) / (2ε)`.  
   Use the looser tolerance `isapprox(out, ref; rtol = 1e-6, atol = 1e-8)`, since central differences have `O(ε²)` truncation plus `O(eps/ε)` roundoff.
3. Cache test: call the real `rhs!` with `H1`, then call `vjp_H!` with a different `H2`, and compare against the reference at `H2`. The original cache-reading version fails; the corrected version passes.
4. Check that `out[1]` and `out[N]` are not forced to zero and match the reference for generic `H`; frozen `dH` endpoints do not mean zero gradient w.r.t. endpoint `H`.
