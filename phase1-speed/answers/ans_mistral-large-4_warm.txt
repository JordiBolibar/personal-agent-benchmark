```julia
function heat_step!(T::Matrix{Float64}, kappa::Float64, dt::Float64, dx::Float64)
    nx, ny = size(T)
    (nx >= 2 && ny >= 2) || throw(ArgumentError("T must be at least 2x2"))

    Told = copy(T)          # explicit scheme: update uses only old values
    r = kappa * dt / dx^2   # Fourier number

    # Interior points: standard 5-point Laplacian
    @inbounds for j in 2:ny-1, i in 2:nx-1
        T[i,j] = Told[i,j] + r * (Told[i+1,j] + Told[i-1,j] + Told[i,j+1] + Told[i,j-1] - 4*Told[i,j])
    end

    # Edges: zero-flux means the ghost cell equals the boundary cell value,
    # so the missing neighbor contributes one extra copy of Told on the boundary
    @inbounds for i in 2:nx-1
        T[i,1]  = Told[i,1]  + r * (Told[i+1,1]  + Told[i-1,1]  + Told[i,2]   - 3*Told[i,1])
        T[i,ny] = Told[i,ny] + r * (Told[i+1,ny] + Told[i-1,ny] + Told[i,ny-1] - 3*Told[i,ny])
    end
    @inbounds for j in 2:ny-1
        T[1,j]  = Told[1,j]  + r * (Told[2,j]   + Told[1,j+1]  + Told[1,j-1]  - 3*Told[1,j])
        T[nx,j] = Told[nx,j] + r * (Told[nx-1,j] + Told[nx,j+1] + Told[nx,j-1] - 3*Told[nx,j])
    end

    # Corners: two ghost cells, each equal to the corner value itself
    @inbounds begin
        T[1,1]   = Told[1,1]   + r * (Told[2,1]    + Told[1,2]    - 2*Told[1,1])
        T[nx,1]  = Told[nx,1]  + r * (Told[nx-1,1] + Told[nx,2]   - 2*Told[nx,1])
        T[1,ny]  = Told[1,ny]  + r * (Told[2,ny]   + Told[1,ny-1] - 2*Told[1,ny])
        T[nx,ny] = Told[nx,ny] + r * (Told[nx-1,ny]+ Told[nx,ny-1] - 2*Told[nx,ny])
    end

    return T
end
```

## 1. Von Neumann stability in 2D

The scheme is

T^{n+1}_{i,j} = T^n_{i,j} + r (T^n_{i+1,j} + T^n_{i-1,j} + T^n_{i,j+1} + T^n_{i,j-1} − 4 T^n_{i,j}),  with r = κ·dt/dx².

Look for a Fourier mode T^n_{i,j} = ξⁿ exp(i(k_x·i·dx + k_y·j·dx)), where ξ is the amplification factor per step. Substituting, the spatial differences give

e^{iθx} + e^{−iθx} + e^{iθy} + e^{−iθy} − 4 = 2cos θx + 2cos θy − 4 = −4(sin²(θx/2) + sin²(θy/2)),

with θx = k_x·dx, θy = k_y·dx. So

ξ = 1 − 4r (sin²(θx/2) + sin²(θy/2)).

Stability needs |ξ| ≤ 1 for every mode. The largest ξ is 1 (θx = θy = 0, the constant mode — always neutral, as expected since Neumann BCs conserve the mean). The smallest is at θx = θy = π (the checkerboard mode):

ξ_min = 1 − 8r.

The condition ξ_min ≥ −1 gives 8r ≤ 2, i.e. r ≤ 1/4, so

**dt ≤ dx² / (4κ)**.

The boundary treatment does not tighten this limit; the interior analysis gives the binding constraint.

## 2. What changes in 3D

The Laplacian now has 6 neighbors instead of 4, so

ξ = 1 − 4r (sin²(θx/2) + sin²(θy/2) + sin²(θz/2)),

and ξ_min = 1 − 12r at θx = θy = θz = π. The condition becomes r ≤ 1/6, i.e.

**dt ≤ dx² / (6κ)**.

In d dimensions the pattern is dt ≤ dx² / (2d·κ): each extra dimension adds one more neighbor pair and costs a factor in the allowed timestep.

## 3. What happens when the condition is violated

If r > 1/4, the highest-frequency modes (near the checkerboard, θx ≈ θy ≈ π) get |ξ| > 1. These modes grow every timestep and flip sign each step, so you see a growing checkerboard oscillation that quickly swamps the smooth solution and ends in Inf/NaN after finitely many steps. Even at exactly r = 1/4 the checkerboard mode has ξ = −1: it neither grows nor decays, so any noise at that frequency persists forever. Just inside the limit the scheme is stable but high-frequency errors decay only slowly, so the solution can look jagged for a long time. In short: violating the condition does not give a wrong-but-plausible answer, it gives an explosive, sign-flipping instability.

## 4. Complexity per timestep

O(nx·ny) time — a fixed number of flops per grid cell, plus one O(nx·ny) copy of the array for the old values — and O(nx·ny) extra memory for that copy. In terms of N = nx·ny cells, it is O(N) per step, so O(N·M) for M steps. In practice the kernel is memory-bandwidth bound, since every step reads and writes the whole grid.
